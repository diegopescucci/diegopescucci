## Progetto

### [UniTo Student Assistant Bot](https://github.com/diegopescucci/unito-bot)

Bot Telegram scritto in Python per aiutare studenti di Informatica UniTo a consultare informazioni sugli esami.

- Acquisisce anno e corso durante la configurazione iniziale.
- Recupera l’elenco degli esami dal portale di Informatica UniTo tramite scraping.
- Mostra dettagli degli esami e conserva le preferenze utente in un file JSON locale.
- Integra Telegram Bot API, Requests, BeautifulSoup e python-dotenv.
